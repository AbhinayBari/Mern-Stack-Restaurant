Food Ordering Website

About the Project

This is a Food Ordering Website built using React.js and Node.js. The project allows users to explore food items and place orders.

Technologies Used

- React.js
- JavaScript
- Node.js
- Express.js
- MongoDB

Features

- User Registration and Login
- Food Menu
- Order Placement
- Backend API Integration

Project Structure

- "frontend/" - React frontend application
- "backend/" - Node.js and Express backend application

Installation and Setup

1. Clone the Repository

git clone https://github.com/AbhinayBari/Mern-Stack-Restaurant.git

2. Start the Frontend

cd frontend
npm install
npm run dev

3. Start the Backend

Open another terminal:

cd backend
npm install

Configure the required environment variables in your local ".env" file, then run the backend using the start command defined in "backend/package.json".
